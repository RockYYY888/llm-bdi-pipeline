\section{Methodology}
\label{sec:method}

\subsection{Certified Atomic-Core Compilation}
\label{sec:atomic-core-compilation}

\subsubsection{Certification Boundaries}

GP2PL separates deterministic input validation from two compiler certification
stages. Atomic compilation checks every candidate branch locally through
$\operatorname{Cert}_D(b)$, records its completion summary $\Sigma_b$, and
retains the certified subset $\mathcal C^{\checkmark}_{D,E}$. Clingo then selects
$\mathcal M_D$ from the feasible family whose members satisfy evidence and
schema-achievement coverage, internal-call closure, and compatible progress and
dependency ranks. Query compilation reuses the selected summaries to construct
a transition certificate recording an occurrence-specific preservation
portfolio $\boldsymbol\Pi_\chi$ and serialization $\boldsymbol\ell_\chi$ for each
DFA progress guard $\chi$; it neither reopens atomic selection nor relearns
$\mathcal M_D$.

After these obligations are certified, rendering preserves each selected trigger,
context, ordered body, and internal-call edge. The Technical Appendix
formalizes the constructors and accept/reject boundary, proves the
soundness and monitor claims, and provides pseudocode (Secs.~1--3).

\subsubsection{Evidence Normalization and Lifting}

Figure~\ref{fig:compiler-stages}(a) summarizes the query-independent path from
raw evidence through canonical lifting and certified candidate selection to
$\mathcal M_D$.
An evidence provider is admissible when its provider-native singleton-goal
policy representation $\mathcal E_{\mathrm{raw}}$ parses to an evidence program $E_0$.
Canonical lifting produces
$E=\operatorname{Lift}_D(E_0)$, whose rules pair a partial state condition and
one goal atom with a PDDL action macro, numeric effects, and provenance.
Every symbol and arity must occur in $D$. Canonical lifting normalizes a policy
already generalized by the provider rather than inferring one from ground
plans; it consistently renames variables while preserving shared-variable
structure and declared constants (Technical Appendix,
Sec.~\ref{app:formal-framework}). Atomic evidence is
restricted to positive singleton achievements;
negative literals remain guard conditions and do not induce synthetic atomic
goals.

\subsubsection{Action-Schema Candidate Generation}

Candidate generation extends evidence goals to every schema-producible target,
including signatures required by internal calls but absent from provider
evidence.
Let $\operatorname{goalPred}(E)$ contain the predicate symbols targeted by
positive predicate evidence and $\operatorname{prod}(D)$ the predicates
occurring in some action's add effects; the domain-wide producible target
universe is
\[
T_D(E)=\operatorname{goalPred}(E)\cup\operatorname{prod}(D).
\]
Every add-effect predicate thus receives candidate atomic modules. Predicates
with neither validated evidence nor a positive producer receive no candidate
modules; static and
delete-only predicates remain non-achievement context. Supported numeric
equalities form $T_D^{\mathbb Z}(E)$, the admitted singleton integer-equality
targets in $E$.

The finite grammar $\mathfrak G$ contains constructors: producer,
regression, recursion, precondition repair, resource discharge, and numeric
progress. For Boolean and numeric targets, $\textsc{LiftSchemas}$ computes
\[
\mathcal C_D(E)=
\operatorname{Inst}_D(\mathfrak G,T_D(E),T_D^{\mathbb Z}(E)),
\]
using only typed schemas and effects from $D$, then alpha-normalizes each
branch.
For target set $T$, graph $\mathcal G_D^{\mathrm{prod}}(T)$ has edge
$p\rightarrow r$ when a producer
for $p$ has a positive dynamic precondition with predicate $r$.
Backward STRIPS regression
\cite{Fikes1972GeneralizedRobotPlans,Alcazar2013Regression,Chen2026Moose}
over an acyclic reachable graph rejects conflicting deletes, stops
before an alpha-normalized regression state repeats, and retains the shortest
body for each equivalent completion summary. Candidate generation is finite
without an arbitrary action-depth constant; validated
evidence macros are never truncated. Symbolic progression verifies every
candidate, while cyclic dependencies require provider evidence or a
certified recursive module. Let $\mathcal C_E$ be the validated evidence
branches. The candidate set
$\mathcal C_{D,E}=\mathcal C_E\cup\mathcal C_D(E)$ is finite. The finite
candidate language is not complete for PDDL planning: some valid plans may lie
outside $\mathfrak G$. PDDL types constrain unification, and rendered
sort-membership tests appear only in plan contexts.

\subsubsection{Candidate Certification}

Symbolic progression proves preconditions and target achievement. It yields
each candidate's completion summary $\Sigma_b$, with Boolean
projections $\mustadd_b$, $\mayadd_b$, and $\maydelete_b$, any exact
constant-integer delta, and a keyed resource-mode transition. The $\mustadd_b$
facts hold after every feasible completion; $\mayadd_b$ and $\maydelete_b$
overapproximate possible effects. The branch predicate
$\operatorname{Cert}_D(b)$ holds exactly when typed binding, symbolic
executability, target achievement, and every applicable constructor-specific
progress or resource condition have valid witnesses. The selected core must
additionally satisfy the set-level condition
$\operatorname{Closed}_D(\mathcal M_D)$; the definitions follow.

\paragraph{Binding, symbolic execution, and internal-call closure.}
Action and subgoal variables must be bound by the trigger, positive context, or
validated static sort membership; negative contexts and comparisons only
filter.
$\operatorname{Closed}_D(\mathcal R)$ holds when every internal call in plan set
$\mathcal R$ type-unifies with a selected trigger under $D$'s type hierarchy.
Requiring $\operatorname{Closed}_D(\mathcal M_D)$ is a set-level Clingo
obligation that proves call resolution, not universal branch applicability.

\paragraph{Recursive progress.}
A same-predicate recursive branch $b$ requires a ranking function
$\rho_b:\operatorname{States}(D)\rightarrow\mathbb N$, either a non-negative
global relation count or an anchor-local count
$\rho_{R,x}(s)=|\{y\mid R(y,x)\in s\}|$ that strictly decreases under a
reachable-state acyclicity assumption, together with an
already-satisfied, direct-producer, or validated-evidence terminal branch.
Relation threats are checked over the preparation graph selected by Clingo: a
branch may add the ranked relation at another anchor only under a guard proving
that the new anchor differs from the protected one. The compile-time witness
applies only to generated, schema-certified features and follows relational
progress witnesses in
general-policy work \cite{Frances2021LearningGeneralPolicies}.

\paragraph{Target-preserving resource discharge.}
Temporary resource occupation is inferred from paired availability and
occupancy effects. The compiler forms a finite graph of alpha-normalized keyed
occupancy modes. A discharge body is accepted only if symbolic execution
removes the current mode, restores availability, leaves the atomic target true,
and does not recreate an earlier normalized mode. Excluding repeated modes
makes the search finite without assuming a one-action release.

\paragraph{Ranked cross-module precondition repair.}
Preparing one dynamic precondition may temporarily change another. A repair
branch may defer an unrelated sibling precondition
only through a schema-inferred single-valued fluent when every deferred sibling
has a unique producer, all static feasibility witnesses remain valid, and each deferred
precondition is restored before the original target is retried. For a candidate core
$\mathcal M$, Clingo assigns each trigger signature in its selected call graph
a dependency rank $\kappa_{\mathcal M}$ that strictly decreases along every
selected call edge; same-predicate recursion instead requires its own relational
ranking witness.

\subsubsection{Feasible-Core Optimization}

Validated evidence macros and certified action-schema-derived candidates enter
one Clingo answer-set optimization problem
\cite{Gebser2018Clingo}. Evidence rules induce coverage obligations
$\operatorname{covers}_D(b,e)$, and nonrecursive schema branches induce
$\operatorname{realizes}_D(b,c)$. Both require alpha-equivalent triggers and an
equivalent or no-weaker completion contract; the Technical Appendix,
Sec.~\ref{app:formal-framework},
defines their admissible alternatives.
Define
\begin{align*}
\mathcal C^{\checkmark}_{D,E}
  &=\{b\in\mathcal C_{D,E}\mid\operatorname{Cert}_D(b)\},\\
\mathfrak F_{D,E}
  &=\{\mathcal M\subseteq\mathcal C^{\checkmark}_{D,E}\mid
      \mathcal M\models\Omega_{D,E}\land
      \operatorname{Closed}_D(\mathcal M)\},
\end{align*}
where $\Omega_{D,E}$ contains evidence coverage, schema-achievement coverage,
preparation acyclicity, and recursive-ranking compatibility, and resource
discharge is part of the per-branch predicate $\operatorname{Cert}_D$.
The optimizer uses the
lexicographic objective
\begin{multline*}
\mathcal M_D=\operatorname*{lexargmin}_{\mathcal M\in\mathfrak F_{D,E}}
\bigl\langle-N_{\mathrm{rel}}(\mathcal M),-N_{\mathrm{prep}}(\mathcal M),
|\mathcal M|,\\
N_C(\mathcal M),N_\beta(\mathcal M)\bigr\rangle,
\end{multline*}
where $N_{\mathrm{rel}}$ and $N_{\mathrm{prep}}$ count compatible
relation-ranked recursion and acyclic precondition-repair capabilities,
$N_C$ counts context literals, and $N_\beta$ counts body steps. The selected
trigger--context--body rules, rather than their AgentSpeak rendering, define
$\mathcal M_D$; the claim is global only within
$\mathcal C^{\checkmark}_{D,E}$, not over ungenerated programs.

A concrete Blocks World derivation through the selected atomic core appears in
the Technical Appendix, Fig.~S1.

\subsection{Certified Query Compilation}
\label{sec:temporal-composition}

\subsubsection{Controlled Natural-Language Translation}

A frozen language-model prompt receives one controlled natural-language request,
its declared typed parameters and constraints, and the public PDDL catalogue. The
language model returns an unbound parametric \ltlf{} query formula and a
one-to-one proposition table. The result is interpreted under
the achievement-query and TEG classes defined in Sec.~\ref{sec:background}.
Deterministic validation rejects
undeclared symbols, wrong arities or types, unsupported operators, incomplete
atom tables, and altered parameter constraints; it neither grounds parameters
nor selects actions or objects. Query invocation supplies $\theta_q$. For
offline evaluation, a hidden gold formula enables exact finite-trace language
equivalence; it is not an online input. The complete prompt and structured output
contract appear in the Technical Appendix, Sec.~\ref{app:translation-prompt}.
Figure~\ref{fig:compiler-stages}(b)
follows the validated execution formula through its MONA DFA, progress-edge
certification, query-local repair controllers, and top-level dispatcher to
$\mathcal Q_q$. GP2PL uses $F\varphi_q$ for achievement queries and $\varphi_q$
for TEGs. Both classes share DFA construction, certification, monitoring, and
transition repair; no separate achievement path is introduced.

\paragraph{Progress-edge compilation.}
Given the validated bound query $\widehat\tau_q$ and DFA $\mathcal D_q$ of its
execution formula from Sec.~\ref{sec:background}, GP2PL compiles one controller
for each progress source--target pair $(q_s,q_t)$, grouping its conjunctive guard
records only when they share a certified common signed repair objective. Thus
DFA-derived alternatives are supported, whereas arbitrary disjunctive achievement
choice lies outside $\Phi_{\mathrm{cert}}(D,\mathcal M_D)$. An accepting
\texttt{true} self-loop requires no controller. For signed obligation
$\mathcal O_\chi=\langle P_\chi^+,P_\chi^-\rangle$, compilation derives a
serialization $\boldsymbol\ell_\chi$ and occurrence-specific preservation
portfolios $\boldsymbol\Pi_\chi$ from the selected completion summaries. The
transition certificate records the selected branches, a completeness check for
their summaries, the induced threat relation, and the checked order. If
this certificate cannot be constructed, compilation rejects the progress edge;
otherwise $\boldsymbol\ell_\chi$ is rendered as the balanced binary
transition-repair tree of Sec.~\ref{sec:balanced-trees}.

\subsubsection{Summaries and Preservation Portfolios}

A relational fixed point over selected calls computes each branch summary
$\Sigma_b$, following the definite/potential effect distinction in BDI
goal-interference analysis \cite{Thangarajah2003GoalInterference}. For positive
occurrence $G_i\in P_\chi^+$, a preservation portfolio
$\Pi_{\chi,i}\subseteq\mathcal M_D$ contains the certified branches allowed to
establish $G_i$ under the obligations protected at that occurrence. Portfolios
are occurrence-specific: two occurrences of the same predicate may admit
different branches.

A negative guard $\neg N$ is satisfied by observing $N$ absent or by applying an
exact certified deleter; it never becomes a synthetic $!\neg N$ goal. A portfolio
branch is admissible only when its conditional $\mayadd$ excludes $N$. For a
chosen portfolio tuple, the
threat-induced precedence graph
$\mathcal G_\chi=(P_\chi^+,\prec_\chi)$ places $G_j$ before $G_i$ when a feasible
$\maydelete$ of $\Pi_{\chi,j}$ may delete $G_i$. An acyclic graph yields a
topological serialization. If no portfolio choice removes a cycle, compilation
requires a joint branch $b_\chi^{\mathrm{joint}}$ whose complete net effect
establishes the entire guard, is callable from every positive occurrence it
establishes, and retains every query variable. Compilation rejects the edge if
no such joint branch exists.

\subsubsection{Numeric and Joint-Guard Certification}

Numeric obligations reuse the same certification machinery. A positive
integer equality is achieved by a complete constant-delta action: a unit delta
requires strict direction, and a larger delta requires the exact predecessor value. A
mixed Boolean--numeric guard requires complete action-only net effects that
establish its Boolean atoms and exact integer values while preserving every
other signed obligation. Negated equality is observation-only
without a certified change-away action. Numeric preparation uses
$\rho_{\mathrm{num}}=\langle n_{\mathrm{miss}},d_{\mathrm{target}}\rangle$,
ordering missing preconditions before bounded target distance. Strong-Until
source invariants are the signed literals common to every non-progress
self-loop guard and are preserved until progress.

\subsubsection{Balanced Binary Transition-Repair Trees}
\label{sec:balanced-trees}

For query $q$, let $\mathcal R_{q_s,\chi}$ denote the plans for one source-state
transition obligation; the query-local plan set $\mathcal Q_q$ contains the
top-level dispatcher together with every accepted $\mathcal R_{q_s,\chi}$, one
per progress obligation. Each $\mathcal R_{q_s,\chi}$ realizes
$\boldsymbol\ell_\chi$ by recursively splitting contiguous literal ranges at
their midpoint. Internal nodes dispatch two child ranges, leaves observe or
repair one signed literal, and the completion plan retries only while the
monitor remains at $q_s$. The transition certificate, rather than the tree
shape, provides the temporal guarantee. Trigger fan-out denotes the number of sibling
AgentSpeak plans sharing one transition-repair trigger. Flat control therefore
has trigger fan-out $O(n)$, whereas a linear realization has plan-body length
$O(n)$; balanced dispatch preserves the certified order while bounding both
local quantities by two.

Appending $\mathcal Q_q$ leaves $\mathcal M_D$ unchanged. Query-local goals are
control symbols; only primitive PDDL actions change the observed state.

\subsection{Conditional Guarantees}
\label{sec:guarantees}

These guarantees apply only to accepted branches, cores, and query controllers;
each proposition states its branch-local, candidate-space, or
supported-composition boundary.

\paragraph{Atomic branch soundness.}
\textbf{Proposition 1.} If an emitted $p(\bar X)$ branch's context holds under a
type-consistent grounding and called modules satisfy the achievement
contract and completion summary established by its certification, the branch
is executable and returns with $p(\bar X)$. Binding grounds each term; induction
over symbolic progression establishes preconditions and achievement;
recursion uses its ranking and preparation rechecks the producer context.
\hfill$\square$ This establishes local soundness, not
reachable-state coverage.

\paragraph{Selection optimality.}

\textbf{Proposition 2.} For a grounded feasible-core selection instance, a
Clingo optimum $\mathcal M_D$ belongs to $\mathfrak F_{D,E}$ and minimizes the
declared lexicographic cost over that feasible family. The result does not imply
complete candidate generation or optimality over all AgentSpeak programs.

\paragraph{Supported transition-composition soundness.}

\textbf{Proposition 3.} Let $\mathcal O_\chi=\langle
P_\chi^+,P_\chi^-\rangle$ be an accepted signed transition obligation. If each
required signed repair has an applicable certified branch,
each selected call terminates, and later repairs preserve earlier obligations,
then at the end of a complete transition-repair pass the controller retries
exactly when the monitor reports the source state; otherwise the controller returns to
dispatch at the
current state. Every intervening state change is an actual DFA edge enabled by
the observed valuation, and a rejecting state cannot report success.

\paragraph{Proof sketch.}
Induction over the certified order shows that each leaf
establishes its signed literal and later summaries preserve prior positives and
absences; if a call leaves the source, the remaining certified suffix preserves
the established prefix at return boundaries. Because only the monitor evaluates full cubes
after every primitive action, every observed source exit is a real DFA
transition. After a complete pass, the completion plan retries exactly while the source
remains active. \hfill$\square$ This does not guarantee that a post-exit suffix
avoids rejection.

\paragraph{Structural and monitor-fidelity guarantees.}
The balanced tree for $n$ signed literals and $e$ repair plans has
$2n+e+2$ plans, fan-out and body length at most two, and depth $O(\log n)$
while preserving the certified order (Proposition~4). After every successful
primitive action, the runtime monitor state equals the deterministic automaton
state over the observed finite trace, so leaving a controller source state is
exactly a DFA exit and controller plans cannot write monitor beliefs
(Proposition~5). If the initial valuation is accepting, execution
commits no primitive action and denotes the one-state trace
$\langle s_0\rangle$ rather than a noop, which could change
strong-Next or Until truth (Proposition~6).
